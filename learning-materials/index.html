建议的阅读方式

  • 3 分钟速览：读标题下的一句话定义 → 跳到"个人解释" → 再看文末前两条来源。
  • 10 分钟扎实学：合上资料，口头回答"自测问题"，再展开折叠区对照答案。
  • 对比读：学完一个概念后，把它和相邻概念一起看——多数理解卡点不在概念本身，而在它与邻居的边界。

如何新增一份概念

  1. 在 WorkBuddy 中输入：用 concept-learning-generator 学习 <概念名>
  2. Skill 触发后，按 .workbuddy/skills/concept-learning-generator/SKILL.md 的 Step 1–5 执行
  3. 新资料落到 learning-materials/<slug>.html
  4. 在本索引的表格中追加一行（由 Skill 一并完成）

本目录所有 HTML 均为内联 CSS 单文件，无外部样式依赖，可离线双击打开；其中 concept-relationship.html 的 Mermaid 图配有文字兜底，离线或 CDN 失效时仍可读懂。

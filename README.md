# 📊 统计与数据分析 学习笔记

> 记录学习「统计与数据分析」课程的笔记、代码、作业与心得。

## 🎯 课程目标

- 掌握**描述统计、概率分布、抽样估计、假设检验**等统计学核心概念
- 学会使用 **Python**（NumPy、Pandas、Matplotlib、SciPy、scikit-learn）进行数据处理与可视化
- 能独立完成一个小型数据分析项目

## 🛣️ 学习路线

1. **基础统计** —— 描述统计、集中趋势与离散程度、概率基础
2. **概率分布** —— 离散分布（二项、泊松）、连续分布（正态、t、卡方）
3. **推断统计** —— 抽样分布、置信区间、假设检验（z / t / 卡方）
4. **数据分析工具** —— Python 数据科学生态、SQL 基础
5. **可视化** —— Matplotlib、Seaborn 图表规范
6. **实战项目** —— 真实数据集端到端分析

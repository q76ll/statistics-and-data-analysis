# 01 - 描述统计（Descriptive Statistics）

> 用若干关键数字概括一组数据的整体特征：集中趋势、离散程度、分布形状。

## 1. 集中趋势（Central Tendency）

| 指标 | 定义 | 适用 | 特点 |
|---|---|---|---|
| **均值** Mean | 所有数据之和 / 个数 | 对称分布、无极端值 | 受极端值影响大 |
| **中位数** Median | 排序后正中间的数 | 有偏分布、有极端值 | 不受极端值影响 |
| **众数** Mode | 出现次数最多的数 | 分类数据 | 可能不唯一 |

> 💡 **经验法则**：右偏分布中，均值 > 中位数；左偏则反之。

## 2. 离散程度（Dispersion）

| 指标 | 定义 | 备注 |
|---|---|---|
| **极差** Range | max − min | 对异常值敏感 |
| **方差** Variance | 各数据与均值偏差平方的平均 | 有量纲问题 |
| **标准差** Std | 方差的平方根 | 与原数据同量纲，最常用 |
| **四分位距** IQR | Q3 − Q1 | 衡量中间 50% 的离散度，对异常值稳健 |

## 3. 分布形状（Shape）

- **偏度（Skewness）**：分布对称性
  - = 0：对称（如正态分布）
  - > 0：右偏（长尾在右）
  - < 0：左偏（长尾在左）
- **峰度（Kurtosis）**：分布陡缓 / 尾部厚度

## 4. 五数概括与箱线图

最小值、Q1、中位数、Q3、最大值 → 用 **箱线图（Box Plot）** 一眼看出：

- 中心位置（中位数）
- 离散程度（箱体高度 = IQR）
- 异常值（Q1−1.5·IQR 以下、Q3+1.5·IQR 以上的小圆点）

## 5. Python 速算

```python
import numpy as np
from scipy import stats

data = [12, 15, 18, 22, 22, 25, 30, 100]   # 最后一个是异常值

print("均值:",       np.mean(data))
print("中位数:",     np.median(data))
print("标准差:",     np.std(data, ddof=1))   # 样本标准差
print("Q1, Q3:",     np.percentile(data, [25, 75]))
print("偏度:",       stats.skew(data))
```
